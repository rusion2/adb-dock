# ADB Dock 开发进度

## 当前状态

`v0.1.3-beta.3` 发布前通过了 35 项核心检查、33 项原生 Windows 界面检查和 16 项隔离安装检查。发布后从公开链接下载了安装包，并与本地构建的 SHA-256 核对一致。

`v0.1.3-beta.4` 增加了浮窗位置记忆。首次收起时，浮窗默认停在工作区右侧三分之一高度处，圆角会随停靠边更新。核心和原生界面检查增加了同一序列号重连的用例，覆盖 ADB 监听或设备列表查询失败时保留操作，以及传输 ID 变化时结束旧连接上的操作。原生界面检查还覆盖首次停靠、恢复位置和按目标显示器计算停靠位置。

原生客户端使用 C#、.NET 10 和 WPF。设备命令和安装流程的自动检查使用模拟客户端、测试目录或临时注册表。早期真机只读检查及各版本的验收结果见[历史开发与验收记录](archive/development-history.md)。

## 待验收

- 真机插拔、USB 调试授权、离线和网络设备变化时的反馈。
- 在用户主动执行或授权后，验收真机截图、APK 安装、按键、Logcat、投屏及其断连行为。
- 实际鼠标拖动与取消、悬停焦点、托盘点击和复杂多窗口交互。
- 100%、125%、150%、200% 缩放，以及不同 DPI 的双屏切换、显示器移除和不同任务栏位置。
